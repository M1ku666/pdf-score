# 图标目录

这里的 **一个 `.svg` 文件 = 一个图标**。组件 `<AppIcon name="..." />` 直接按文件名取用，
所以**换图标、加图标都不用改任何代码**。

## 怎么用

```vue
<AppIcon name="chevronLeft" :size="20" />
```

- 文件名用 **kebab-case**（`chevron-left.svg`），`name` 用 **camelCase**（`chevronLeft`），
  `AppIcon` 内部自动换算，两种写法都能对上文件。
- `size`（默认 22）与 `stroke`（默认 1.9）控制尺寸与描边粗细，颜色固定跟随文字色（`currentColor`）。

## 怎么换一个图标

用一个同名文件覆盖掉它即可，比如把从 Lucide 下载的 `trash.svg` 直接覆盖 `trash.svg`。
**任何标准 SVG 都能直接丢进来**，因为 `AppIcon` 会：

1. 读取根 `<svg>` 上的 `viewBox`（没有就按 `0 0 24 24` 处理）；
2. 丢掉根 `<svg>` 本身，只把它内部的内容注入到组件自己的 `<svg>` 里。

也就是说，文件根 `<svg>` 上的 `width` / `height` / `stroke` / `fill` / `class` 会被忽略，
尺寸和颜色一律由组件属性决定，不会因为换了个图标就破坏布局或配色。

## 怎么加一个图标

1. 往这个目录丢一个 `.svg`；
2. 在组件里写 `<AppIcon name="文件名" />`。

图标名打错时不会报错，而是回退到 `info`；**DEV 下控制台会打印一条 warn** 指出缺哪个文件，
照着提示改名即可。

## 三条注意

- **实心图形**要在子元素上自己写 `fill="currentColor" stroke="none"`（见 `play.svg`），
  否则会继承组件根上的 `fill="none"`，看起来就是空白。
- **描边粗细可以在子元素上覆盖**（写 `stroke-width="…"`，盖掉组件根上的 1.9）。四个标记工具的图标
  （`row` / `barline` / `section` / `repeat-start` / `repeat-end`，反复按状态用后两个）用这一手分成两档：
  **谱线 = 1、标记 = 1.9 及更粗**（反复的粗线 2.8、细线 1.2）——谱表是背景、标记是前景，
  换图标时**别把谱线一起加粗**，那样整个图标会糊成一片。
- 这里的图标全部是**内联矢量**（构建时以字符串打进 JS，无额外网络请求）。
  新增图标不必考虑体积，但也别把整包图标集倒进来。
